# Bili Turbo（B站海外加速）

## 安装
1. 解压这个 zip，得到 `bili-turbo` 文件夹
2. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择 `bili-turbo` 文件夹
4. 刷新 B 站视频页即可生效

## 它做了什么
- **换 CDN**：B站给海外用户分配的 cosov / akamai / aliov 镜像经常很慢，换成 hw / 08c / ali / cos 镜像（同一个签名链接通用），并按成功率自动排序
- **分块并发**：把播放器的大请求拆成 512KB 小块，4 路并发
- **对冲请求**：某块 2.5 秒没回来，就向另一个镜像再发一次，谁先到用谁
- **预读缓存**：每个文件往后预读 12MB，存在内存里（上限 160MB）

## 查看状态
在视频页按 F12 打开控制台，输入：
```js
__biliTurbo.status()
```
`playerBufferSec` 是播放器当前领先的缓冲秒数，`hosts` 是镜像排序（冒号后数字越小越好）。

## 调参数
控制台里可以直接改，例如：
```js
__biliTurbo.CFG.aheadBytes = 30 * 1024 * 1024  // 预读加到 30MB
__biliTurbo.CFG.switchCdn = false              // 关闭换 CDN
```
想永久改，就编辑 `content.js` 顶部的 `CFG`，然后在扩展页点刷新。

## 注意
- 镜像列表是根据当前网络实测选出来的，B站以后可能调整；如果某天突然加载不了，先把 `switchCdn` 关掉试试
- 只改下载方式，不改视频内容；不能解锁大会员画质
